# 2. Website Philosophy

Do not build a generic attorney website.

The site should feel like a premium presentation instead of a collection
of sections.

Think in scenes, not pages.

Scene 1 - Light environment - Hero - Austin portrait

Scene 2 - Background gradually darkens - Trust - Credentials

Scene 3 - Full black environment - Practice Areas - Additional content

The transition between scenes should feel natural.

------------------------------------------------------------------------

# 3. Navigation

Desktop: - Horizontal navigation. - Logo mark on the far left. -
Wordmark to the right of the logo. - Navigation links centered/right. -
Primary CTA on the far right.

Responsive: - Never allow navigation to wrap. - At the defined
breakpoint, collapse links into a hamburger menu. - The logo remains
visible. - Mobile menu should feel premium, not generic.

Whitespace is preferred over squeezing links.

------------------------------------------------------------------------

# 4. Hero

Large editorial typography.

Austin's portrait replaces the inspiration image.

Minimal copy.

Primary CTA.

Secondary CTA.

Huge breathing room.

------------------------------------------------------------------------

# 5. Typography

Desktop: Very large headings.

Laptop: Scale proportionally.

Tablet: Remain bold.

Mobile: Still large and impactful. Do not shrink headings excessively.

Maintain strong hierarchy across all devices.

------------------------------------------------------------------------

# 6. Color System

Primary Gold #C19E61

Supporting: #A98445 #D0AF77

Black #0B0B0D

Charcoal #18181B

White #F6F5F3

# 7. Motion

Motion should reinforce professionalism.

Avoid flashy effects.

Prefer: - fades - reveals - parallax where appropriate - subtle image
movement - restrained hover states

------------------------------------------------------------------------

# 8. Technical Expectations

Engineer: - reusable components - scalable design tokens -
accessibility - responsive behavior - performance-first implementation

No implementation shortcuts.
